Sala de Estar — Portfólio Pessoal

Um portfólio interativo que convida o visitante a explorar uma sala de estar virtual. Cada objeto conta uma história: os vinis revelam projetos, o laptop mostra ferramentas, e o telefone abre os contactos.

O conceito nasceu da ideia de criar um espaço digital que se sente como um lugar onde queremos ficar — acolhedor, pessoal e cheio de detalhes para descobrir.

O Desafio

Criar um portfólio que não fosse apenas uma galeria de trabalhos, mas uma experiência imersiva. O visitante deveria sentir curiosidade ao entrar — como quando entramos numa sala e queremos explorar cada canto. O desafio técnico foi combinar interações complexas com performance e responsividade.

O Processo

Começou com research de portfólios interativos e referências visuais. A ideia da sala de estar surgiu como metáfora perfeita: um espaço pessoal, acolhedor, onde cada objeto tem significado. O wireframing foi feito em Figma, iterando sobre a disposição dos elementos e as micro-interações.

A fase de desenvolvimento trouxe desafios técnicos interessantes: a animação de abertura dos vinis com efeito 3D, o sistema de carousel com drag gesture, o vinyl player funcional com playlist real, e o modo dia/noite com transição suave em todos os elementos.

Papel: UI/UX Design, Front-end Development, Interaction Design

Ferramentas: Figma, HTML, CSS, JavaScript, Illustrator

Destaques Técnicos:

• Design responsivo com 4 breakpoints optimizados
• Carousel de vinis com animação 3D de abertura
• Modo dia/noite com transição suave
• Vinyl player funcional com playlist integrada
• Efeito dock magnification nos ícones
• Formulário de contacto com validação
• Container queries para escalabilidade dos popups
• Animações CSS performantes com GPU acceleration

Resultado

Este projeto representa a intersecção entre o analítico e o criativo — cada interação foi pensada para surpreender sem comprometer a usabilidade. A sala de estar tornou-se mais do que um portfólio: é um convite para ficar, explorar, e descobrir.

Nota: As imagens de base foram geradas por inteligência artificial e posteriormente alteradas e manipuladas com Photoshop e Figma.
